# אפליקציית תזונה ומעקב משקל (אישית)

אפליקציה שרצה כולה בטלפון שלך. אין שרת, אין חשבון, אין מנוי.
כל הנתונים נשמרים בטלפון בלבד (באחסון המקומי של הדפדפן).

## מה יש בשלב הזה
- שאלון קצר וחישוב יעד קלוריות יומי (נוסחת Mifflin–St Jeor) וחלוקה לפחמימות/חלבון/שומן.
- יומן אכילה יומי עם ארבע ארוחות, עריכה ומחיקה.
- מוצרים אישיים, מועדפים, וארוחות שמורות לשימוש חוזר.
- העתקת יום קודם.
- מעקב משקל עם גרף וממוצע נע של 7 ימים.
- ייצוא גיבוי (JSON) וייצוא יומן (CSV), ושחזור מגיבוי.
- מסך בדיקות שמריץ את פונקציות החישוב מול תוצאות ידועות.

---

## העלאה ל-GitHub Pages (חינם) — פעם אחת

1. היכנס ל-https://github.com והתחבר.
2. לחץ על **+** בפינה הימנית-עליונה ← **New repository**.
3. תן שם, למשל `nutrition`. בחר **Public**. לחץ **Create repository**.
4. בעמוד הריק שנפתח לחץ על הקישור **uploading an existing file**
   (או: לשונית **Add file** ← **Upload files**).
5. גרור לתוך החלון את **כל הקבצים** מהתיקייה הזאת
   (index.html, app.js, calc.js, style.css, sw.js, manifest.webmanifest,
   icon-180.png, icon-192.png, icon-512.png). את README.md לא חובה.
6. למטה לחץ **Commit changes**.
7. למעלה: **Settings** ← בתפריט הצד **Pages**.
8. תחת **Branch** בחר **main** ו-**/ (root)**, ולחץ **Save**.
9. המתן דקה-שתיים ורענן. בראש העמוד יופיע הקישור, בצורה:
   `https://<שם-המשתמש>.github.io/nutrition/`

זה הקישור לאפליקציה.

## התקנה באייפון (Add to Home Screen)

1. פתח את הקישור ב-**Safari** (דווקא Safari, לא Chrome).
2. לחץ על כפתור השיתוף (ריבוע עם חץ למעלה).
3. גלול ובחר **הוסף למסך הבית / Add to Home Screen**.
4. אשר. סמל האפליקציה יופיע במסך הבית ותיפתח במסך מלא, כמו אפליקציה.

מרגע ההתקנה היא עובדת גם בלי אינטרנט.

## חשוב לדעת על הנתונים
- הנתונים נשמרים **בטלפון הזה בלבד**, בתוך האפליקציה.
- מחיקת נתוני האתר בדפדפן, או מחיקת האפליקציה, תמחק אותם.
- לכן כדאי מדי פעם: **הגדרות ← ייצוא גיבוי (JSON)** ולשמור את הקובץ
  (ב-iCloud/קבצים/מייל לעצמך). בטלפון חדש אפשר לשחזר ממנו.

## עדכון האפליקציה בעתיד
כדי לפרסם גרסה חדשה: מעלים מחדש את הקבצים ששונו לאותו repository
(Add file ← Upload files ← Commit). האפליקציה מושכת עדכונים אוטומטית
בפתיחה הבאה עם אינטרנט. הנתונים האישיים לא נמחקים בעדכון.
